# ATM-SYSTEM
The ATM System is a secure banking application that enables customers to perform transactions such as cash withdrawal, cash deposit, balance inquiry, fund transfer, mini statement, and PIN change. It securely communicates with the bank server and ATM hardware to authenticate users and process transactions accurately.
